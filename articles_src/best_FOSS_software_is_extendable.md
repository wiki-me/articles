# the best open source software is easily extendable open source software

I woulld argue closed source companies don't want you to be able to easily extend and improve the software. If you can pay someone else to improve it or improve it yourself that means you won't pay them. Firefox and wordpress are highly popular and are made better using extensions and i don't believe they would be popular without the ability to extend them.

the best projects can make it easier to extend the software by:
1) having the ability to find and install extension using the software itself without doing any research. discovering this ability should also be easy and displayed in the GUI.
2) There should be reviews that help decide if the extension is good and worthwhile. just trying random things is too time consuming.

This way you can allow a bunch of creative geniuses extend the software. these geniuses will be inaccessible to the closed source competitor.
