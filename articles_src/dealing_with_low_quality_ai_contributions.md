# Suggestions for dealing with AI operated accounts and too many low quality AI contributions

There has been some talk about AI bots making contributions on github.

I also helped somebody debug a game ([bash fighter](https://github.com/Bash-Entertainment/bash-fighter)) on [lemmy](https://join-lemmy.org/) and it turned out to be a bot . I only found  a disclosure after i looked at its profile. that is negligence at best. There should be a blacklist somewhere . If github refuses to allow integrading with shareeable blocklists other FOSS alternatives could implement it (e.g. codeberg/forgejo). maybe with the ability to pay a fine to get out of it.

Or maybe have a whitelist with a small fee to get into? that depends on how much a project wants PR or issues (PR seems like the more important thing to regulate for quality). For some projects it might be best to use a whitelist and for others it might not be.

Other then that maybe projects should document in the read me that github accounts interacting with the project must be operated directly by a human.
