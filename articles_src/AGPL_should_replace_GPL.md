# Because today virtually any software can potentially run on cloud services like geforce now, the gpl is mostly obsolete, use the AGPL

Because any software or game can potentially be converted to a cloud platform (like geforce now),  this means GPL software should be under the AGPL.

Technically I can take a highly popular game like Mindustry, and run it on some server, the input from the keyboard and mouse gets sent to the server , and the output (pictures) sent to my screen, I am not distributing the software so I can change the code with proprietary enhancements and make money from the improved version without giving the changes back.

I could do the same thing for theoretically any other software, including highly popular one like the GIMP or Krita.

Of course I am assuming here you think a copyleft (or reciprocal) license like the GPL/AGPL is beneficial, see [this](https://github.com/wiki-me/articles/blob/main/articles_src/Why_copyleft.md) article for arguments for using a copyleft license.

I have emailed the free software foundation about this. The response I got basically agreed with this analysis.

IANAL but I think a project needs to get every contributor to agree to a re-license , at least if it wants to avoid legal risk, so it is better to do it as soon as possible.
